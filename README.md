# おせっかい勇者 Prototype v17

## 魔法使い
- 常に浮遊状態。方向キーで慣性をつけて滑る
- 魔法の絨毯に乗る見た目へ変更
- 旧ジャンプボタンは「風押」へ変更
- 風押：正面へ風弾を飛ばし、命中した落下中スライムを横へ1列押す
- 炎：上下左右ファイアボール
- 氷：正面アイスショット
- 風替：正面のスライムとその上を入れ替える
- 蒼氷解放：青全消去＋氷解除
- 凍結中へのファイアボールは1発目で解凍、次で破壊

## UI
- 操作ボタンの文字を職業別に変更
  - 勇者：掴 / 跳 / 剣 / 蹴
  - モンク：持 / 二段 / 拳 / 蹴
  - 魔法使い：風替 / 風押 / 炎 / 氷
- 職業選択はタップしただけでは開始しない
- 職業をタップすると操作説明を表示
- 「この職業で開始」ボタンを別に追加
