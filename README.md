# おせっかい勇者 Prototype v12

## 共通
- 連鎖ポイント300でステージクリア
- 必殺ゲージ100%＋攻撃長押し→離す、で職業固有技

## 勇者（赤）
- 服装を赤基調へ変更
- 通常スライムは剣一撃
- 紅蓮斬：赤スライムを全消去

## モンク（緑）
- 勇者とは別デザインのオリジナルキャラクター
- 緑の袖なし道着、濃緑の帯・鉢巻、素手
- ジャンプは勇者より約2マス高い
- 横パンチ：対象1個だけ横1マス（ダルマ落とし）。移動不能なら破壊
- 上パンチ：頭上へのアッパー。落下スライムをカウンターで破壊。頭上の着地済みスライムも破壊
- 下パンチ：足元のスライムを破壊
- キック：対象1個だけ横方向の端/障害物手前まで吹っ飛ばす
- 掴み：1個だけ取り外して持ち歩き、再度掴みで置く
- 翠気功波：緑スライムを全消去。緑の波動エフェクト付き

## 将来案
- 魔法使い＝青を基調にした職業として追加予定


## v13 修正
- 魔法使いは今回は追加せず保留
- モンクは掴み中にジャンプ不可
- モンクは地上ジャンプ後、空中でもう1回ジャンプできる2段ジャンプへ変更
- スマホ長押し時のコピー・翻訳・テキスト選択系UIを出にくくする設定を追加
- モンクの脚を素足色から濃緑のズボンに変更。靴は従来どおり

## v14 勇者強化
- 勇者がスライムを掴んだ状態で「掴」ボタンを長押しすると、そのスライムの色を変化させられる
- 色順は固定で 赤 → 黄 → 緑 → 青 → 赤
- 長押しを続けると一定間隔で次の色へ循環するため、狙った色で離せる
- 着地済み・落下中どちらの掴みスライムにも対応
- モンクにはこの能力は付かない
