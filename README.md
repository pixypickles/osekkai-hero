# おせっかい勇者 Prototype v21

## ステージ進行
- 通常ステージは連鎖ポイントでクリア
- Stage 1 → Stage 2 → Stage 3 → BOSS
- 通常ステージは進むほど必要連鎖ポイントが増加
- クリア後に「次のステージへ」「タイトルへ戻る」を表示

## ボス戦
- 1個ずつ大量のスライムが落下
- 無色スライムも混ざる
- 画面右端・中段にボス、HP制
- スライムをボスへぶつけるとダメージ
- 勇者：剣・蹴りの直接攻撃でもダメージ
- 魔法使い：ファイアボールとアイスショットは直接ダメージ
- 魔法使い：風替・風押は直接ダメージなし（スライムを動かして当てる用途）
- ボス撃破後は次の通常ステージへ進める

## 勇者
- ジャンプ高度を約1マス上げた
