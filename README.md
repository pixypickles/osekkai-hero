# おせっかい勇者 Prototype v54

- ステージ1〜3は従来どおり
- ボス1後のステージ4〜6に、たまに飛行する使い魔が出現。無色スライムを1個落として去る
- 使い魔は各職業の通常攻撃で撃破可能
- 強ボス後にステージ7〜9を追加。落下速度をさらに高速化
- ステージ7〜9は使い魔に加えてスケルトン戦士が出現
- スケルトンは歩行・ジャンプ・接近剣攻撃。被弾すると吹き飛び＋2秒ダウン
- 勇者・モンクのガードはスケルトン剣にも有効
- ステージ9クリア後に魔王戦
- 魔王は画面中段よりやや下を楕円軌道で飛行し、ファイアボールと接近剣攻撃
- 魔王戦は左右端だけ無色スライムが降り、中央寄りに固定リフト2基
- 魔王HP 64
