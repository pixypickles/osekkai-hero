# osekkai-hero Prototype v2

前版の見た目・操作・落下表現を修正したブラウザ試作です。

## v2変更点
- 勇者を頭・目・髪・胴・腕・脚・ブーツ・マント・剣で描画
- スライム2個組が上から連続的に落下して着地するよう変更
- スマホ方向キーに上下を追加
- 上/下＋剣で方向攻撃
- CPUは一応接続を評価しつつ、約28%で雑な列を選択
- スコア上昇で落下速度アップ、硬めスライム出現
- 長押しチャージ、連鎖ゲージ、十字斬りを維持

`index.html` をブラウザで開いてください。

## v3 修正
- 剣を実際に大きく振るアニメーションを追加
- 左右・上・下それぞれ専用の斬撃方向と軌跡
- チャージ斬りは射程も増加
- 掴みを実動作化。隣接スライムを掴んでぶら下がる
- 掴み中にジャンプで離脱・再ジャンプ
- 上に積まれていないスライムは掴み中に左右へ引っ張れる
- 掴み状態を黄色の接続表現で可視化

## v4 修正
- 通常攻撃を大振りの斬撃から「突き」に変更。左右・上・下へ細く狙える
- 落下中の2個組にも攻撃判定を追加
- 落下中のスライムにもHPを持たせ、空中撃破可能
- 落下中のスライムを近距離で掴める「空中キャッチ」を追加
- 空中キャッチ中は落下を止め、ジャンプ/掴みでリリース
- 盤面上の掴み・引っ張りも維持
- CPUの本格的な「ぷよを左右移動・回転して置く」表現は次段階のTODO

## v5 修正
- 落下中スライムに物理当たり判定を追加。ジャンプ/移動ですり抜けない
- 上から乗る、下から頭をぶつける、横からぶつかる判定を追加
- 落下中スライムを掴んでも落下は停止せず、そのまま一緒に降りるエレベーター挙動へ変更
- 掴み中は落下ペアの向き・上下順を変更しない
- 着地時に掴みを解除し、上下入れ替わりの原因だった再配置処理を廃止
- 剣を短く調整
- スライムの角丸を強め、目も丸く変更

## v6 修正
- 着地済みスライムの横移動は、移動先の直下に地面/スライムの足場がある場合だけ可能
- 空中の高さのまま壁へ張り付く挙動を禁止
- 掴んだスライムを左右どちらにも動かせるため、引っ張りだけでなく押し込みも可能
- 掴み時の勇者をスライムの横に配置して、押す/引く見た目を改善
- 剣身を線描画から先細りポリゴンへ変更し、剣先を尖らせた

## v7 修正
- 掴み移動: 引っ張りは足場必須、押す場合は足場がなくても1マス押し出して落とせる
- 落下スライムに上から潰された場合、上へワープせず横へ弾かれて約0.4秒気絶
- キックボタン追加。向いている横方向へ1マス移動
- キックは「上に何も載っていない着地済みスライム」と「落下中スライム」の両方に対応
- 落下ペアを配列管理に変更し、前の組が完全着地する前から次の組が降り始める
- PCでは K キーがキック

## v8 修正
- キック時に勇者が実際に片足を横へ蹴り出すアニメーションを追加
- 落下スライム掴み中からジャンプした際、スライムから少し離してから跳ぶようにし誤った「いてっ！」判定を防止
- 必殺ボタンを削除
- 必殺ゲージ100%時は剣を長押しチャージして離すと必殺発動
- 通常のチャージ攻撃はゲージ未満なら従来どおり強い突き
- 剣攻撃時に残っていた右下方向の斬撃補助線を削除

## v9 修正
- 掴みボタンで勇者が実際に手を伸ばすアニメーションを追加
- 掴み判定を少し広げ、正面・斜め・約2マス先まで候補を探すよう調整
- 下敷き時の「いてっ！」表示を削除
- 下敷きになると勇者が一瞬横に広がって縦に潰れる「ペラペラ」表現を追加
- 剣がスライムに当たった瞬間に白いヒットスパークを表示
- スライム側にも色付きリング＋目のフラッシュを表示し、ダメージを受けたことを視覚化

## v10 修正
- 上から潰されても気絶しない仕様へ変更
- 通常の押し潰しは、横の空いている方向へ「にゅるっ」と押し出される挙動に変更
- 左右をスライム等に塞がれた状態で上から潰された場合は、細長くなりながら上方向の空間まで押し出される
- 掴みの当たり判定の広さは維持
- 掴み時に見える腕だけ短くし、剣より長く見えないよう調整
