# おせっかい勇者 Prototype v121

スクリーンショットから3点修正。

- マスが細くなる原因:
  ヒーラーを8×16のCSS Grid本体へ追加していたため、ヒーラー自身が129個目のグリッド要素になりレイアウトを壊していた。
  専用の絶対配置オーバーレイを新設し、盤面グリッドから完全分離。

- ヒーラーが見えない原因:
  盤面外の負座標から開始し、盤面の overflow:hidden でキャラまで切られていた。
  上端に姿が見える位置から開始し、白魔道士本人がふわっと降下してからターゲットが出るよう変更。

- 異常な落下速度:
  ヒーラーの滑らかな重力更新用50〜90msタイマーで、CPUカプセルまで毎回1マス落としていた。
  キャラ物理とカプセル落下を分離。カプセルは約650ms/1マス、ヒーラーだけ高頻度で弱重力更新。
