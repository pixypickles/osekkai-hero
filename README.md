# osekkai-hero Prototype v2

前版の見た目・操作・落下表現を修正したブラウザ試作です。

## v2変更点
- 勇者を頭・目・髪・胴・腕・脚・ブーツ・マント・剣で描画
- スライム2個組が上から連続的に落下して着地するよう変更
- スマホ方向キーに上下を追加
- 上/下＋剣で方向攻撃
- CPUは一応接続を評価しつつ、約28%で雑な列を選択
- スコア上昇で落下速度アップ、硬めスライム出現
- 長押しチャージ、連鎖ゲージ、十字斬りを維持

`index.html` をブラウザで開いてください。

## v3 修正
- 剣を実際に大きく振るアニメーションを追加
- 左右・上・下それぞれ専用の斬撃方向と軌跡
- チャージ斬りは射程も増加
- 掴みを実動作化。隣接スライムを掴んでぶら下がる
- 掴み中にジャンプで離脱・再ジャンプ
- 上に積まれていないスライムは掴み中に左右へ引っ張れる
- 掴み状態を黄色の接続表現で可視化

## v4 修正
- 通常攻撃を大振りの斬撃から「突き」に変更。左右・上・下へ細く狙える
- 落下中の2個組にも攻撃判定を追加
- 落下中のスライムにもHPを持たせ、空中撃破可能
- 落下中のスライムを近距離で掴める「空中キャッチ」を追加
- 空中キャッチ中は落下を止め、ジャンプ/掴みでリリース
- 盤面上の掴み・引っ張りも維持
- CPUの本格的な「ぷよを左右移動・回転して置く」表現は次段階のTODO

## v5 修正
- 落下中スライムに物理当たり判定を追加。ジャンプ/移動ですり抜けない
- 上から乗る、下から頭をぶつける、横からぶつかる判定を追加
- 落下中スライムを掴んでも落下は停止せず、そのまま一緒に降りるエレベーター挙動へ変更
- 掴み中は落下ペアの向き・上下順を変更しない
- 着地時に掴みを解除し、上下入れ替わりの原因だった再配置処理を廃止
- 剣を短く調整
- スライムの角丸を強め、目も丸く変更

## v6 修正
- 着地済みスライムの横移動は、移動先の直下に地面/スライムの足場がある場合だけ可能
- 空中の高さのまま壁へ張り付く挙動を禁止
- 掴んだスライムを左右どちらにも動かせるため、引っ張りだけでなく押し込みも可能
- 掴み時の勇者をスライムの横に配置して、押す/引く見た目を改善
- 剣身を線描画から先細りポリゴンへ変更し、剣先を尖らせた
