# osekkai-hero prototype

仮題 **「転生したら落ちゲーの中でした。～おせっかい勇者の連鎖救出記～」**

落ちものパズルを絶妙に下手なCPUがプレイし、その盤面内にいる勇者が剣・ジャンプ・掴みで「お節介」して連鎖を手助けするスマホゲームのブラウザ試作です。

## 起動
`index.html` をブラウザで開くだけです。ローカルHTTPサーバーを使う場合:

```bash
python -m http.server 8000
```

## 現在の試作要素
- 8x14盤面 / 4色
- 同色4個以上の上下左右接続で消去・連鎖
- 接続を狙うが25%程度で雑な判断をするCPU
- 左右移動、ジャンプ、剣、掴み
- 攻撃長押しチャージ
- 通常スライム2HP
- スコア上昇後に硬めスライム(4HP)出現
- 連鎖で必殺ゲージ増加
- 必殺「おせっかい十字斬り」: 上下左右2マス＋斜め1マス
- PCキーボード / スマホ用画面ボタン
